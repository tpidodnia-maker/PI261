# ДЗ: Массивы и строки (Модуль 2)

7 заданий, каждое — отдельный проект.

## Задание 1 — Одномерный и двумерный массивы

- `A` — 5 целых чисел, вводятся с клавиатуры.
- `B` — матрица 3×4 дробных чисел, заполняется `Random`.
- Вывод `A` в строку, `B` — матрицей.
- Ищется общий max, min, сумма и произведение всех элементов.
- Сумма чётных элементов `A`.
- Сумма нечётных столбцов `B` (1-й и 3-й, считая с 1).

**Запуск:** `cd Задание1 && dotnet run`

## Задание 2 — Сумма между min и max

Матрица 5×5, случайные числа от −100 до 100.
Ищем позиции минимального и максимального элемента, затем суммируем всё, что стоит между ними по порядку обхода.

**Запуск:** `cd Задание2 && dotnet run`

## Задание 3 — Шифр Цезаря

Сдвиг на 3. Латинские буквы шифруются, остальные символы не трогаем.
Обратный сдвиг (−3) даёт расшифровку.

**Запуск:** `cd Задание3 && dotnet run`

## Задание 4 — Операции над матрицами

Матрицы 3×3:
- умножение матрицы на число,
- сложение матриц,
- произведение матриц.

**Запуск:** `cd Задание4 && dotnet run`

## Задание 5 — Калькулятор выражений

Вводится строка вида `10+20-5`, поддерживаются только `+` и `-`.
Число собирается по цифрам, знак запоминается, результат накапливается.

**Запуск:** `cd Задание5 && dotnet run`

## Задание 6 — Заглавная буква в предложении

Идём по символам, флаг `newSentence` говорит, что следующая буква — начало предложения.
После `.`, `!`, `?` флаг снова включается.

Пример:
```
today is a good day for walking. i will try to walk near the sea
→ Today is a good day for walking. I will try to walk near the sea
```

**Запуск:** `cd Задание6 && dotnet run`

## Задание 7 — Недопустимые слова

Текст задан в коде, недопустимое слово — `die`.
Слово ищется целиком (по буквам), заменяется на `***` такой же длины, в конце выводится статистика замен.

**Запуск:** `cd Задание7 && dotnet run`
