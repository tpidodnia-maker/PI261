# LEG BATTLES — Ноговые битвы

Конкурент Slap Battles, но вместо перчаток — ноги. Полный проект с нуля: 12 обувей со способностями, процедурная арена, кик-система с заряженными ударами, магазин, Last Standing.

## Механики

| Механика | Описание |
|---|---|
| 🦵 Кик | ЛКМ — удар, удержание — заряженный удар (×2 отброс) |
| 🎯 Хиткон | Конус 45°, 8 стадов, крит сзади ×1.5, в прыжке +50% |
| 👟 12 обувей | От Кроссовок до Бога Ноги (Cosmic) |
| ⚡ Способности | Рывок, фаза, полёт, молния, время, заморозка |
| 🗺 Арена | 3 уровня, трамплины, ямы, процедурная генерация |
| 🏆 Last Standing | Каждые 5 мин — выживи 60с = Wins |
| 💀 Kills = валюта | Убийства покупают новую обувь |
| 🔥 Серии | 3/5/10 подряд = бонусный XP |

## Обувь

| Обувь | Редкость | Способность | Цена |
|---|---|---|---|
| Кроссовки | Common | — | 0 |
| Кеды-прыгуны | Common | Двойной прыжок | 100 |
| Ботинки-щиты | Common | Блок (ПКМ) | 250 |
| Кроссы-ракеты | Uncommon | Рывок (Shift) | 500 |
| Ледяные ботинки | Uncommon | Заморозка | 750 |
| Магнитки | Rare | Притяжение | 1500 |
| Прыгучие сапоги | Rare | Землетрясение | 2500 |
| Фазовые тапки | Epic | Фаза (Shift) | 5000 |
| Штормовые берцы | Epic | Молния (E) | 8000 |
| Драконьи лапы | Legendary | Полёт (F) | 15000 |
| Хроно-сапоги | Mythic | Время (E) | 30000 |
| Бог Ноги | Cosmic | Всё сразу | 100000 |

## Управление

- **ЛКМ** — удар (удерживай для заряженного)
- **ПКМ** — блок ( Botинки-щиты)
- **Shift** — рывок / фаза
- **E** — молния / время
- **F** — полёт
- **Tab** — магазин

## Установка

### Способ A: Pлагин (рекомендуется)
Сгенерируй установщик (см. ниже) и положи в `%LOCALAPPDATA%\Roblox\Plugins`.

### Способ B: Rojo
```bash
rojo serve default.project.json
```

### Способ C: Вручную
Структура как в DESIGN.md — shared → ReplicatedStorage/Shared, server → ServerScriptService, client → StarterPlayerScripts.
